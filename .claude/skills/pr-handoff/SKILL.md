# Branch and PR handoff

Write a handoff another teammate can use without asking you on chat.

Include:

- Branch name, and whether it is rebased on latest main
- Files changed, and which directories others should avoid until this merges
- How to run the app and tests, with commands you actually ran and their results
- What is done, what is unfinished, and any risk to the demo path
- Next agent or human role, and the first command they should run

Do not claim the branch is merged. If main moved, pull or rebase first and report conflicts. End with the Handoff format from CLAUDE.md.
